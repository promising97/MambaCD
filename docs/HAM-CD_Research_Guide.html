1. 项目与改进总览

本项目基于 ChangeMamba 二元变化检测框架，在 SpatialMamba 骨干网络上进行改进，训练入口为 train_HAM-CD.py，模型封装为 MambaBCD_spatial.py。

1.1 相对原始代码的三处核心改动

改动点原实现现实现文件
StarModule 频域 8×8 patch 上 rfft2 + 可学习频域权重 fft_FSAS GaborFreqTransform(q) 分式 Gabor 卷积 StarIR_FMB.py
DFFN 频域 输出后 patch 级 rfft2 + fft 参数 GaborFreqTransform(x) StarIR_FMB.py
解码器 stage 单路 StarBlock(x) 双路：StarBlock(x) + GaborFPU(x) → 1×1 融合 ChangeDecoder_StarBlock.py
当前生效的 Decoder 文件：changedetection/models/ChangeDecoder_StarBlock.py
由 MambaBCD_spatial.py 第 25 行导入。HAM-CD 训练/推理均通过 STMambaBCD 间接使用此解码器。

1.2 建议的论文方法命名（可自定义）

  • 整体方法：HAM-CD（Hierarchical Attention-Mamba Change Detector）或自定义名称
  • StarBlock 内 Gabor：Gabor-enhanced Star Attention（GESA）
  • 解码器 FPU 分支：Parallel Gabor Frequency Perception Unit（PG-FPU）

2. 整体架构

输入: pre_image (B,3,H,W) + post_image (B,3,H,W) │ ┌───────────┴───────────┐ ▼ ▼ Backbone_SpatialMamba Backbone_SpatialMamba （权重共享 / 双时相各跑一次） │ │ └───────────┬───────────┘ ▼ 四层特征 [f1,f2,f3,f4] × 2时相 │ ▼ ChangeDecoder_StarBlock（4 阶段金字塔解码） │ ▼ Conv2d(128→2) + bilinear 上采样 │ ▼ 变化图 logits (B,2,H,W)

2.1 解码器每个 Stage 的数据流（当前版本）

x = OverlapPatchEmbed(cat(pre_feat, post_feat)) # → 128 通道 x_up = upsample_add(上一 stage 输出, x) # stage II~IV star_out = StarBlock(x) # 内含 Gabor 版 StarModule + DFFN fpu_out = GaborFPU(x) # SFS-Conv 频域感知分支 p = Conv1x1(cat(star_out, fpu_out)) # 256→128

6. Decoder：ChangeDecoder_StarBlock

6.1 四阶段金字塔

Stage输入特征dim_convertStarBlockFPU

IIcat(f3_pre, f3_post) + upsample(p4)dim_convert31starblock2fpu_3

6.2 forward 核心代码逻辑

p40 = self.dim_convert41(torch.cat([pre_feat_4, post_feat_4], dim=1))
p4  = self.fpu_fuse_4(torch.cat([
        self.starblock1(p40),
        self.fpu_4(p40)
    ], dim=1))

p30 = self._upsample_add(p4, self.dim_convert31(torch.cat([pre_feat_3, post_feat_3], dim=1)))
p3  = self.fpu_fuse_3(torch.cat([self.starblock2(p30), self.fpu_3(p30)], dim=1))
# ... 同理 stage III、IV
return p1   # 128 通道特征图

OverlapPatchEmbed：3×3 conv，stride=1，padding=1，将拼接后的 encoder 特征映射到 128 维。

_upsample_add：双线性上采样 + 残差相加，实现 FPN 式特征融合。

7. StarBlock 与 Gabor 改造

文件：StarIR_FMB.py

7.1 StarBlock 结构

StarBlock(x): x = x + StarModule(norm(x)) # 注意力分支 x = x + DFFN(norm(x)) # 前馈分支 return x

7.2 StarModule（改动重点）

hidden = self.to_hidden(x)
q, v = self.to_hidden_dw(hidden).split([dim, dim], dim=1)
v = self.SMB(v)                    # SpatialMambaBlock 处理 v

out = self.gabor_freq(q)           # ★ 原: patch rfft2 × fft_FSAS
out = self.norm(out)
out = self.spatial(v) * out        # Star 门控：空间 × 频域
out = self.plain_channel(out) * out# 通道注意力 CMU
return self.project_out(out)

7.3 DFFN（改动重点）

x = self.project_in(x)
x = self.dwconv(x)
x1, x2 = self.spatial(x).chunk(2, dim=1)
x = F.gelu(x1) * x2
x = self.project_out(x)
x = self.gabor_freq(x)             # ★ 原: patch rfft2 × fft
return x

7.4 GaborFreqTransform（sfs_conv.py）

class GaborFreqTransform(nn.Module):
    # 多方向多尺度 Fractional Gabor 核 × 可学习参数 t → conv2d
    kernel = self.gabor(self.t)    # gabor: 16 个方向/尺度组合
    return F.conv2d(x, kernel, padding=pad)  # 保持 H×W 不变

Gabor 核公式（分式阶 order=0.25）：

G(xθ,yθ) = exp(-((xθ² + (yθ/s)²)^order)) · cos(2π·xθ/s)
角度 θ ∈ {0°,45°,90°,135°}，尺度 s ∈ {1,2,3,4}

8. SFS-Conv FPU 分支

文件：sfs_conv.py 中的 GaborFPU

8.1 GaborFPU 结构

class GaborFPU(nn.Module):
    # 输入通道 4 等分，各走一个 GaborSingle
    x1,x2,x3,x4 = split(x, C//4)
    out = cat([gabor(x1), gabor(x2), gabor(x3), gabor(x4)])
    out = fc1x1(out)
    out = out + x   # 残差

8.2 GaborSingle vs GaborFreqTransform

模块用途后处理
GaborFreqTransformStarBlock 内替换 FFT仅 conv，尺寸不变
GaborSingle（FPU内）解码器并行频域分支relu + dropout + maxpool

8.3 与完整 SFS-Conv 的关系

完整 SFS-Conv 包含 SPU（空间）+ FPU（频域）+ CSU（通道选择）。当前解码器仅引入 FPU 分支，空间路径由 StarBlock 承担，融合用 1×1 Conv 而非 CSU。
